# RFID Door Security System 

An Arduino-based **RFID door security system** built using an MFRC522 RFID reader to provide secure access control. The system verifies registered RFID cards and controls an electronic door lock through a relay.

## Features

* RFID-based access control
* Authorized card verification
* Relay-controlled door lock
* Green LED for authorized access
* Red LED for unauthorized access

## Components

* Arduino UNO
* MFRC522 RFID Reader
* RFID Cards/Tags
* Relay Module
* Green LED
* Red LED
* Buck Converter

## Technologies Used

* Arduino
* C++
* RFID
* Embedded Systems
* Object-Oriented Programming
